# Ledger: manual climb of Sep/Xsearch.lean

## Goal

Raise the number of SL-COMP problems proved by `xsearch` (directories `qf_shls_entl` and `qf_shid_entl`, 454 provable of 608) as high as algorithmic changes allow, by supervising Opus subagents that each implement one technique. Only after no further algorithmic gain is found does OpenEvolve resume, then optimising time and lines.

## Goal (phase 3, added 2026-09-26): time climb

S2S solved the whole SL-COMP 2019 set in about 60 s. Bring the full bench (`qf_shls_entl` + `qf_shid_entl`, 5 s cap) from 187 s of valid time (step 22, this Linux i7-13700) toward 60 s by algorithmic improvements, keeping 454 proved and losing none. Orchestrated by the supervising agent with at most 2 Opus subagents (usually 1), sequentially; be aggressive, every step is checkpointed by commit and can be reverted. Acceptance per step: full bench, lost list empty, proved 454, valid total time lower, no problem newly over 3500 ms. Time is measured by `ms` in the CSV, which covers parsing, emitting the predicate definitions, and the goal elaboration; anything inside that window is fair game, including `Bench/` encoding cost, but the EVOLVE-BLOCK remains the primary target. Ping the user at milestones (each accepted step, notable findings). STANDING RULES (user, 2026-09-26): (1) keep the xsimpl interface; speed it up internally, never duplicate it with a parallel normaliser; (2) these are general tactics: no overfitting to SL-COMP, no hard-coded predicate names, shapes, or constants tuned to particular problems; every change must be defensible as a general improvement; the supervising agent reviews each diff for this before accepting.

## Acceptance criteria

- Every accepted step is monotone: full-suite diff against the previous accepted CSV has an empty lost list and a non-empty gained list. A step that loses any problem is sent back, never merged.
- Verification is the full bench on both directories at 5 s: `timeout 2400 lake exe bench --dir qf_shls_entl --dir qf_shid_entl --timeout 5000 --csv evolve/ref/stepN.csv`, diffed by file name against the previous accepted CSV.
- No `sorry`, axioms, `native_decide`, `unsafe`; the `xsearch` tactic syntax, `xsearch_unfold` attribute and `xsearchUnfoldExt` keep working; edits stay inside the EVOLVE-BLOCK of `Sep/Xsearch.lean`; no comments or docstrings in the code.
- The climb ends when the remaining unproved provable problems have no identified technique with reach, or the cost per proof is clearly beyond what evolution should later trade off.
